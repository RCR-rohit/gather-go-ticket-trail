# Gather Go Ticket Trail

Build a modern, fully responsive Event Booking System using React, JavaScript, HTML and CSS. Include a homepage, event listings, search and filters, event details, ticket booking, booking confirmation, My Bookings page and Admin Dashboard. Add sample events, form validation, Local Storage and a clean, attractive UI. Ensure mobile-friendly design and smooth navigation.
